## `updateAppConfig`

更新将被应用到 `nuxt.options.appConfig` 的应用配置。模块可以利用它设置可被用户配置覆盖的默认值。更新会使用 [`defu`](https://github.com/unjs/defu) 与现有配置合并。

### 类型

```ts
function updateAppConfig (appConfig: Record<string, unknown>): void
```

### 示例

```ts
import { defineNuxtModule, updateAppConfig } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    updateAppConfig({
      myModule: {
        option: 'value',
      },
    })
  },
})
```
