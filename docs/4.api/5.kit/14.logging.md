Nuxt 提供了一个 logger 实例，你可以使用它来记录带有额外功能的消息。`useLogger` 允许你获取一个 logger 实例。

## `useLogger`

返回一个 logger 实例。它在底层使用了 [consola](https://github.com/unjs/consola)。

### 用法

```ts twoslash
import { defineNuxtModule, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const logger = useLogger('my-module')

    logger.info('Hello from my module!')
  },
})
```

### 类型

```ts
function useLogger (tag?: string, options?: NuxtLoggerOptions): NuxtLogger
```

### 参数

**`tag`**：一个用于为所有日志消息添加后缀的标签，显示在右侧靠近时间戳的位置。

**`options`**：日志记录器的选项，例如 `level`、`reporters`、`defaults` 和 `formatOptions`。

### 示例

```ts twoslash
import { defineNuxtModule, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const logger = useLogger('my-module', { level: options.quiet ? 0 : 3 })

    logger.info('Hello from my module!')
  },
})
```

## `useTerminal`

返回一组用于与用户终端交互的原语。当 Nuxt 运行在交互式宿主（例如 `nuxt dev` 的终端 UI）中时，
提示（prompt）、任务（task）与通知（notification）都会交给该宿主处理，因此它们既可被应答，也会在一处统一渲染。
否则它们会退回到日志输出。

### 用法

```ts twoslash
declare function runPackageInstall (name: string): Promise<void>
// ---cut---
import { defineNuxtModule, useTerminal } from '@nuxt/kit'

export default defineNuxtModule({
  async setup () {
    const terminal = useTerminal()

    const install = await terminal.prompt('Do you want to install `my-module`?', { type: 'confirm' })
    if (!install) {
      return
    }

    const task = terminal.startTask('Installing `my-module`...')
    // 运行你真正的任务
    await runPackageInstall('my-module')
    task.stop('Installed `my-module`')
  },
})
```

### 类型

```ts
function useTerminal (): NuxtTerminal

interface NuxtTerminal {
  readonly interactive: boolean
  withTerminal: <T>(work: () => Promise<T>) => Promise<T>
  prompt: (message: string, options?: NuxtPromptOptions) => Promise<any>
  startTask: (label: string) => NuxtTerminalTask
  notify: (notification: NuxtTerminalNotification) => NuxtTerminalNotice
}
```

### 属性

**`interactive`**：是否存在交互式宿主。为 `false` 时，下面的这些原语会改为输出到当前进程的流。

**`withTerminal`**：在 `work` 执行期间借用终端，同时挂起宿主的界面并释放 `stdin`。当你需要直接写入终端或从 `stdin` 读取时使用它。并发的调用者会被串行化，而在一次借用之中嵌套的调用会立即执行。

**`prompt`**：向用户提问，并在提示打开期间一直借用终端。它接受与 `logger.prompt` 相同的选项。

**`startTask`**：启动一个长时间运行的任务，在宿主支持时会渲染在其状态区域。用 `task.stop(message?, outcome?)` 结束它，或用 `task.update(label)` 修改它的标签。

**`notify`**：显示一条消息并将其保留在屏幕上，直到用户确认或调用 `notice.dismiss()`。`notice.dismissed` 会在通知消失后被 resolve。
