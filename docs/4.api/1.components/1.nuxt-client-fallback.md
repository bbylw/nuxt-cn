Nuxt 提供了 `<NuxtClientFallback>` 组件，当其任意子组件在 SSR 中触发错误时，在客户端渲染其内容。

::warning
`<NuxtClientFallback>` 已被弃用。[`<NuxtErrorBoundary>`](/docs/api/components/nuxt-error-boundary) 现在也能捕获服务端错误，它的 `retry-on-client` 属性提供了同样的「在客户端重试」行为，并且错误可以通过 `#error` 插槽获取。

| `<NuxtClientFallback>` | `<NuxtErrorBoundary>` |
| --- | --- |
| `<NuxtClientFallback>` | `<NuxtErrorBoundary retry-on-client>` |
| `#fallback` / `#placeholder` 插槽 | `#error` 插槽 |
| `fallback`、`fallback-tag`、`placeholder`、`placeholder-tag` 属性 | `#error` 插槽中的内容 |
| `keep-fallback` | 不写 `retry-on-client` |
| `@ssr-error` | `@error` |

`@ssr-error` 只在服务端触发，而 `@error` 对浏览器中抛出的错误也会触发。如果处理函数只应在服务端运行，请使用 `import.meta.server` 加以保护。
::

::note{to="/docs/guide/going-further/experimental-features#clientfallback"}
该组件是实验性的，要使用它必须在你的 `nuxt.config` 中启用 `experimental.clientFallback` 选项。
::

```vue [app/pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- 该组件将在客户端渲染 -->
    <NuxtClientFallback fallback-tag="span">
      <Comments />
      <BrokeInSSR />
    </NuxtClientFallback>
  </div>
</template>
```

## Events

- `@ssr-error`：当子组件在 SSR 中触发错误时发出的事件。注意这只会触发于服务端。

  ```vue
  <template>
    <NuxtClientFallback @ssr-error="logSomeError">
      <!-- ... -->
    </NuxtClientFallback>
  </template>
  ```

## Props

- `placeholderTag` | `fallbackTag`：指定当插槽在服务端渲染失败时要渲染的回退标签。
  - **类型**：`string`
  - **默认值**：`div`
- `placeholder` | `fallback`：指定当插槽渲染失败时要渲染的回退内容。
  - **类型**：`string`
- `keepFallback`：如果服务端渲染失败，保留回退内容。
  - **类型**：`boolean`
  - **默认值**：`false`

::warning{icon="i-ph-warning-duotone"}
`placeholder` 和 `fallback` 属性以原始 HTML 形式渲染内容。不要将不受信任的用户输入传给这些属性，否则可能导致 XSS 漏洞。对于需要正确转义的动态内容，请改用 `#fallback` 或 `#placeholder` 插槽。
::

```vue
<template>
  <!-- 如果默认插槽渲染失败，在服务端渲染 <span>Hello world</span> -->
  <NuxtClientFallback
    fallback-tag="span"
    fallback="Hello world"
  >
    <BrokeInSSR />
  </NuxtClientFallback>
</template>
```

## Slots

- `#fallback`：指定当插槽渲染失败时在服务端显示的内容。

```vue
<template>
  <NuxtClientFallback>
    <!-- ... -->
    <template #fallback>
      <!-- 如果默认插槽在 ssr 中渲染失败，这会在服务端渲染 -->
      <p>Hello world</p>
    </template>
  </NuxtClientFallback>
</template>
```
