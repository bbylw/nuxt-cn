`<ClientOnly>` 组件用于有意地仅在客户端渲染组件。

:note
默认插槽的内容会在服务端构建中被 tree-shake 掉。（这意味着其中组件所使用的任何 CSS 在渲染初始 HTML 时可能不会被内联。）
:

## Props

- `placeholderTag` | `fallbackTag`：指定服务端渲染的标签。
- `placeholder` | `fallback`：指定服务端渲染的内容。

```vue [app/pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- <Comment> 组件将只在客户端渲染 -->
    <ClientOnly
      fallback-tag="span"
      fallback="加载评论中..."
    >
      <Comment />
    </ClientOnly>
  </div>
</template>
```

## Slots

- `#fallback`：指定在服务端渲染并在浏览器中 `<ClientOnly>` 挂载之前显示的内容。

```vue [app/pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- 这会在服务端渲染 "span" 元素 -->
    <ClientOnly fallback-tag="span">
      <!-- 该组件只在客户端渲染 -->
      <Comments />
      <template #fallback>
        <!-- 这会在服务端渲染 -->
        <p>加载评论中...</p>
      </template>
    </ClientOnly>
  </div>
</template>
```

## 示例

### 访问 HTML 元素

`<ClientOnly>` 内部的组件只有在挂载之后才会渲染。要访问 DOM 中渲染的元素，可以监听一个模板 ref：

```vue [app/pages/example.vue]
<script setup lang="ts">
const nuxtWelcomeRef = useTemplateRef('nuxtWelcomeRef')

// 当组件可用时 watch 会被触发
watch(nuxtWelcomeRef, () => {
  console.log('<NuxtWelcome /> 已挂载')
}, { once: true })
</script>

<template>
  <ClientOnly>
    <NuxtWelcome ref="nuxtWelcomeRef" />
  </ClientOnly>
</template>
```
