`<NuxtPicture>` 是原生 `<picture>` 标签的即用替换组件。

`<NuxtPicture>` 的用法与 [`<NuxtImg>`](/docs/api/components/nuxt-img) 几乎相同，但它还允许在可能时提供 `webp` 等现代格式。

了解更多关于 [MDN 上的 `<picture>` 标签](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/picture)。

## 安装

要使用 `<NuxtPicture>`，你应该安装并启用 Nuxt Image 模块：

```bash [Terminal]
npx nuxt module add image
```
