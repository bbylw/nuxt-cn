`.nuxtrc` 文件可用于以扁平语法配置 Nuxt。它基于 [`unjs/rc9`](https://github.com/unjs/rc9)。

:::tip
对于更高级的配置，请使用 [`nuxt.config`](/docs/directory-structure/nuxt-config)。
:::

## 用法

```bash [.nuxtrc]
# 禁用 SSR
ssr=false

# @nuxt/devtools 的配置
devtools.enabled=true

# 添加 Nuxt 模块
modules[]=@nuxt/image
modules[]=nuxt-security

# 模块安装信息（由 Nuxt 自动添加）
setups.@nuxt/test-utils="3.23.0"
```

如果存在，`nuxt.config` 文件中的属性会覆盖 `.nuxtrc` 文件中的属性。

:::note
Nuxt 会自动添加一个 `setups` 段落来记录模块的安装与升级状态。该段落用于内部的[模块生命周期钩子](/docs/api/kit/modules#using-lifecycle-hooks-for-module-installation-and-upgrade)，不应手动修改。
:::

:::read-more{to="/docs/api/configuration/nuxt-config"}
在 **Nuxt 配置**文档中查看所有可用选项。
:::

## 全局 `.nuxtrc` 文件

你还可以在用户主目录中创建一个全局 `.nuxtrc` 文件，以全局应用配置。

- 在 macOS/Linux 上，该文件位于：

  ```md
  ~/.nuxtrc
  ```

- 在 Windows 上，它位于：

  ```md
  C:\Users\{用户名}\.nuxtrc
  ```

这个全局 `.nuxtrc` 文件允许你定义适用于系统中所有 Nuxt 项目的默认设置。不过，项目级别的 `.nuxtrc` 文件会覆盖这些全局设置，而 `nuxt.config` 的优先级高于两者。
