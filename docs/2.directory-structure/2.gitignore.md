`.gitignore` 文件用于指定 git 应当有意不跟踪、即忽略的文件。

:read-more{icon="i-simple-icons-git" title="git 文档" to="https://git-scm.com/docs/gitignore" target="_blank"}

我们建议 `.gitignore` 文件**至少**包含以下条目：

```bash [.gitignore]
# Nuxt 开发/构建产物
.output
.data
.nuxt
.nitro
.cache
dist

# Node 依赖
node_modules

# 日志
logs
*.log

# 其他
.DS_Store

# 本地环境文件
.env
.env.*
!.env.example
```
