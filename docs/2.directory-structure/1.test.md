`test/` 目录是存放应用测试的推荐位置。Nuxt 不会像扫描 `app/` 或 `server/` 那样扫描它；测试运行器和目录结构都由你自己选择（通常配合 [`@nuxt/test-utils`](/docs/getting-started/testing) 使用）。

一种常见的布局按运行环境划分：

```bash [Directory structure]
-| test/
---| e2e/
---| nuxt/
---| unit/
```

- `test/unit/` —— 不依赖 Nuxt 运行时的快速 Node 测试
- `test/nuxt/` —— 需要 Nuxt 运行时环境的测试
- `test/e2e/` —— 针对正在运行的应用的端到端测试

:::read-more{to="/docs/getting-started/testing#organizing-your-tests"}
请参阅 **Organizing Your Tests**（组织你的测试），了解环境搭建、Vitest 项目（projects）和 TypeScript 上下文。
:::
