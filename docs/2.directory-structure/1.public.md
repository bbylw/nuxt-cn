`public/` 目录中的文件会在根路径下提供，且不会被构建流程修改。这适合那些需要保持文件名不变（如 `robots.txt`）_或_ 不太可能变更（如 `favicon.ico`）的文件。

```bash [Directory structure]
-| public/
---| favicon.ico
---| og-image.png
---| robots.txt
```

```vue [app/app.vue]
<script setup lang="ts">
useSeoMeta({
  ogImage: '/og-image.png',
})
</script>
```

:::tip{to="https://nuxt.com/docs/2.x/directory-structure/static" target="_blank"}
这在 Nuxt 2 中被称为 `static/` 目录。
:::
