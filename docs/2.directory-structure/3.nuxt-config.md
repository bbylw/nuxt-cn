`nuxt.config` 文件的扩展名可以是 `.js`、`.ts` 或 `.mjs`。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  // 我的 Nuxt 配置
})
```

:::tip
`defineNuxtConfig` 辅助函数无需导入即可全局使用。
:::

如果你愿意，也可以从 `nuxt/config` 显式导入 `defineNuxtConfig`：

```ts twoslash [nuxt.config.ts]
import { defineNuxtConfig } from 'nuxt/config'

export default defineNuxtConfig({
  // 我的 Nuxt 配置
})
```

:::read-more{to="/docs/api/configuration/nuxt-config"}
在 **Nuxt 配置**文档中查看所有可用选项。
:::

为确保你的配置是最新的，当 Nuxt 检测到主配置文件、[`.env`](/docs/directory-structure/env)、[`.nuxtignore`](/docs/directory-structure/nuxtignore) 和 [`.nuxtrc`](/docs/directory-structure/nuxtrc) 这些点文件发生变化时，会进行完整重启。
