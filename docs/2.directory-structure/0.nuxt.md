:::important
应将此目录添加到你的 [`.gitignore`](/docs/directory-structure/gitignore) 文件中，以避免将开发构建产物推送到仓库。
:::

如果你想更多地了解 Nuxt 根据你的目录结构生成了哪些文件，这个目录会很有意思。

Nuxt 还提供了一个虚拟文件系统（VFS），让模块可以在不写入磁盘的情况下向此目录添加模板。

你可以通过在开发模式下打开 [Nuxt DevTools](https://nuxt.com/modules/devtools) 并导航到 **Virtual Files**（虚拟文件）标签页来浏览生成的文件。

:::warning
你不应修改其中的任何文件，因为在运行 [`nuxt dev`](/docs/api/commands/dev) 时整个目录会被重新创建。
:::
