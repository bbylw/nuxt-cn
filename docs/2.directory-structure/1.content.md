[Nuxt Content](https://content.nuxt.com) 会读取项目中的 `content/` 目录，并解析 `.md`、`.yml`、`.csv` 和 `.json` 文件，为你的应用创建一个基于文件的 CMS。

- 使用内置组件渲染内容
- 使用类似 MongoDB 的 API 查询内容
- 在 Markdown 文件中通过 MDC 语法使用你的 Vue 组件
- 自动生成导航

:::read-more{to="https://content.nuxt.com" target="_blank"}
了解更多请查阅 **Nuxt Content** 文档。
:::

## 启用 Nuxt Content

一行命令即可在你的项目中安装 `@nuxt/content` 模块，并将其添加到 `nuxt.config.ts` 中：

```bash [Terminal]
npx nuxt add content
```

## 创建内容

将你的 Markdown 文件放入 `content/` 目录：

```md [content/index.md]
# Hello Content
```

模块会自动加载并解析它们。

## 渲染内容

要渲染内容页面，请使用 [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer) 组件添加一个 [全捕获路由](/docs/directory-structure/app/pages/#catch-all-route)：

```vue [app/pages/[...slug\\].vue]
<script lang="ts" setup>
const route = useRoute()
const { data: page } = await useAsyncData(route.path, () => {
  return queryCollection('content').path(route.path).first()
})
</script>

<template>
  <div>
    <header><!-- ... --></header>

    <ContentRenderer
      v-if="page"
      :value="page"
    />

    <footer><!-- ... --></footer>
  </div>
</template>
```
