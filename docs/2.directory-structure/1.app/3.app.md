:::tip
如果你有 `app/pages/` 目录，`app.vue` 文件是可选的。Nuxt 会自动包含一个默认的 `app.vue`，但你仍然可以添加自己的文件，以按需自定义结构和内容。
:::

## 用法

### 最简用法

在 Nuxt 中，[`app/pages/`](/docs/directory-structure/app/pages) 目录是可选的。如果它不存在，Nuxt 将不会包含 [vue-router](https://router.vuejs.org) 依赖。这在构建落地页或不需要路由的应用时很有用。

```vue [app/app.vue]
<template>
  <h1>Hello World!</h1>
</template>
```

::link-example{to="/docs/examples/hello-world"}

### 配合页面使用

当你拥有 [`app/pages/`](/docs/directory-structure/app/pages) 目录时，你需要使用 [`<NuxtPage>`](/docs/api/components/nuxt-page) 组件来显示当前页面：

```vue [app/app.vue]
<template>
  <NuxtPage />
</template>
```

你也可以直接在 `app.vue` 中定义应用的通用结构。当你想包含像页头或页脚这样的全局元素时，这会很有用：

```vue [app/app.vue]
<template>
  <header>
    Header content
  </header>
  <NuxtPage />
  <footer>
    Footer content
  </footer>
</template>
```

:::note
请记住，`app.vue` 充当你 Nuxt 应用的主组件。你向其中添加的任何内容（JS 和 CSS）都将是全局的，并包含在每个页面中。
:::

:::read-more{to="/docs/directory-structure/app/pages"}
了解更多关于如何使用 `app/pages/` 目录构建页面的内容。
:::

### 配合布局使用

当你的应用针对不同页面需要不同布局时，可以使用 `app/layouts/` 目录与 [`<NuxtLayout>`](/docs/api/components/nuxt-layout) 组件。这让你能定义多个布局，并按页面应用它们。

```vue [app/app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

了解更多关于如何使用 `app/layouts/` 目录构建布局的内容。
:::
