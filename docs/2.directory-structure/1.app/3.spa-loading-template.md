当页面以 `ssr: false` 渲染时（在 `nuxt.config` 中全局设置，或通过 [`routeRules`](/docs/guide/concepts/rendering#hybrid-rendering) 为特定路由单独设置），服务端返回的是一个不含服务端渲染内容的 HTML 外壳。在 JavaScript 包下载完成、Nuxt 插件运行完毕并且首个页面渲染出来之前，你的页面内容都是不可见的。

你可以通过添加 `app/spa-loading-template.html` 文件来填补这段空白。它的内容会被直接插入服务端返回的 HTML 中，因此在 Nuxt 客户端包加载之前就已经可见。

```html [app/spa-loading-template.html]
<!-- https://github.com/barelyhuman/snips/blob/dev/pages/css-loader.md -->
<div class="loader"></div>
<style>
  .loader {
    position: fixed;
    top: 50%;
    left: 50%;
    width: 24px;
    height: 24px;
    margin: -12px 0 0 -12px;
    border: 2px solid #efefef;
    border-top-color: #000;
    border-radius: 50%;
    animation: loader 600ms linear infinite;
  }

  @keyframes loader {
    to { transform: rotate(360deg); }
  }
</style>
```

:::warning
这个文件是纯 HTML，它独立于 Vue 渲染，因此你不能在其中使用 Vue 组件或自动导入。请把加载画面所需的样式直接写在这个文件中，而不要依赖你应用的样式表。
:::

:::tip
这个文件只覆盖客户端渲染页面的首次加载。若要在页面之间导航时显示加载状态，请使用 [`<NuxtLoadingIndicator>`](/docs/api/components/nuxt-loading-indicator) 组件。
:::

## 它何时被移除

默认情况下，加载模板渲染在 Nuxt 应用根元素的旁边，而不是在它的内部：

```html
<div id="__nuxt"></div>
<div id="__nuxt-loader"><!-- spa-loading-template.html --></div>
```

它会一直保持可见，直到首个页面准备好渲染（包括页面中的异步 setup），随后被移除。这样可以避免加载画面与你的页面之间出现一次白屏闪烁。包裹元素可以通过 [`app.spaLoaderTag`](/docs/api/nuxt-config#spaloadertag) 和 [`app.spaLoaderAttrs`](/docs/api/nuxt-config#spaloaderattrs) 自定义；请保留一个 `id`，因为 Nuxt 会用它来移除该元素。

你也可以把实验性选项 [`spaLoadingTemplateLocation`](/docs/guide/going-further/experimental-features#spaloadingtemplatelocation) 设为 `'within'`，改为在应用根元素内部渲染它。在这种情况下，它会在 Vue 挂载应用后立即被移除，因此在首个页面准备好渲染之前，画面可能是空白的。

## 配置

Nuxt 会在你的项目以及每个[层（layer）](/docs/directory-structure/layers)的 `app/` 目录（更准确地说，是 [`dir.app`](/docs/api/nuxt-config#dir) 目录）中查找 `spa-loading-template.html`。

你可以通过 [`spaLoadingTemplate`](/docs/api/nuxt-config#spaloadingtemplate) 选项来更改这一行为：

- 一个路径（相对于 [`srcDir`](/docs/api/nuxt-config#srcdir)，默认为 `app/`），用于指定其他 HTML 文件，
- `true`，在找不到文件时使用 Nuxt 内置的加载画面，
- `false`，完全禁用加载模板。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  ssr: false,
  spaLoadingTemplate: 'my-loader.html',
})
```
