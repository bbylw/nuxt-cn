包管理器（[`npm`](https://docs.npmjs.com/cli/commands/npm/)、[`yarn`](https://yarnpkg.com)、[`pnpm`](https://pnpm.io/cli/install)、[`bun`](https://bun.com/package-manager) 或 [`deno`](https://docs.deno.com/runtime/getting_started/installation/)）会创建此目录来存储项目的依赖。

:::important
应将此目录添加到你的 [`.gitignore`](/docs/directory-structure/gitignore) 文件中，以避免将依赖推送到仓库。
:::
