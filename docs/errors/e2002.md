# E2002

`navigateTo()` 接收到一个使用危险协议（`javascript:`、`data:`、`vbscript:`）的 URL。Nuxt 会阻止这些协议以防止 XSS。这几乎总是意味着未经过净化的用户输入传递到了 `navigateTo()`。

## 解决方法

在导航之前，校验并净化用户提供的 URL。只允许 `http:`、`https:` 或相对路径。
