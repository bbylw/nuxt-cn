# E5001

依赖应用清单的代码在 `experimental.appManifest` 被禁用的情况下运行了。该清单为客户端上的路由规则匹配和预渲染载荷检测等特性提供支持，因此必须启用它们才能工作。

## 解决方法

在你的 `nuxt.config` 中启用应用清单：

```ts
export default defineNuxtConfig({
  experimental: {
    appManifest: true,
  },
})
```
