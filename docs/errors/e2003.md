# E2003

`abortNavigation()` 在路由中间件之外被调用了。它只能在中间件处理函数内部取消导航，因此在组件、插件、组合式函数或丢失了中间件上下文的回调中调用它会失败。

## 解决方法

将 `abortNavigation()` 调用移到 `defineNuxtRouteMiddleware()` 处理函数的主体中。
