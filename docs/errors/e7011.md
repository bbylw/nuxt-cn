# E7011

`useCookie()` 无法为 `Set-Cookie` 请求头或 `document.cookie` 序列化 cookie。原始错误会作为 `cause` 附加在抛出的错误上。在以下情况下会抛出该错误：

- cookie 名称中包含 cookie 名称不允许的字符，例如空格、`;` 或 `=`
- 自定义 `encode` 返回的值中包含 cookie 值不允许的字符
- 属性之间彼此矛盾，例如 `sameSite: 'none'`、`partitioned: true`，或者 `__Secure-` / `__Host-` 开头的名称没有配合 `secure: true`，又或者 `__Host-` cookie 设置了 `domain`
- 某个属性无效，例如 `maxAge` 不是整数

## 解决方法

使用合法的 cookie 名称，让 `encode` 返回一个已编码的字符串，并为需要 `secure` 的 cookie 设置 `secure: true`：

```ts
const token = useCookie('token', {
  sameSite: 'none',
  secure: true,
})
```
