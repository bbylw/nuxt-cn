# E6001

在没有活动 Unhead 实例的情况下调用了 head 组合式函数（例如 `useHead()`）。当它在有效的 Nuxt 上下文之外运行时会出现这种情况，例如在 Nuxt 实例不再可用之后的分离异步回调中。

## 解决方法

在组件 `setup()`、Nuxt 插件或路由中间件中同步调用 head 组合式函数。如果你需要在 `await` 之后使用它们，请先捕获 Nuxt 上下文：

```ts
const nuxtApp = useNuxtApp()
await someAsyncWork()
nuxtApp.runWithContext(() => useHead({ title: 'Late title' }))
```
