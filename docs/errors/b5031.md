# B5031

Nuxt 在加载配置时，会从[运行时配置 schema](/docs/guide/going-further/runtime-config#validating-with-a-schema)的 [Standard JSON Schema](https://standardschema.dev/json-schema) 中读取该值的类型和默认值。schema 本身不会包含在你的服务端包中。

当某个 schema 没有实现 Standard JSON Schema，或者 schema 库无法转换它时（例如使用了 transform 的 schema），会报告此错误。为整个 `runtimeConfig` 提供的 schema 也必须描述单个对象，而不能是联合类型（union）。

## 解决方法

使用实现了 Standard JSON Schema 的 schema 库，例如 [Zod](https://zod.dev) 或 [ArkType](https://arktype.io)。将 [Valibot](https://valibot.dev) 的 schema 用 `toStandardJsonSchema()` 包装起来：

```ts [nuxt.config.ts]
import * as v from 'valibot'
import { toStandardJsonSchema } from '@valibot/to-json-schema'

export default defineNuxtConfig({
  runtimeConfig: {
    apiSecret: toStandardJsonSchema(v.string()),
  },
})
```

从运行时配置的 schema 中移除 transform，改为在你读取该值的地方进行转换：

```ts [nuxt.config.ts]
import { z } from 'zod'

export default defineNuxtConfig({
  runtimeConfig: {
    allowedHosts: z.string().transform(value => value.split(',')), // [!code --]
    allowedHosts: z.array(z.string()).default([]), // [!code ++]
  },
})
```
