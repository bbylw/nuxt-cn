# E8014

服务端启动时，Nuxt 会把匹配的环境变量应用到[运行时配置](/docs/guide/going-further/runtime-config)中，并对照每个值的类型检查结果。出现以下情况时服务端不会启动：

- 某个环境变量无法转换为它所替换的值的类型（例如为一个数值型的 `port` 设置了 `NUXT_PORT=abc`）
- 某个[用 schema 声明的值](/docs/guide/going-further/runtime-config#validating-with-a-schema)是必需的，但它没有默认值，也没有任何环境变量为它赋值
- 某个值不在它的 schema 允许的取值之中

每个问题都会指出对应的运行时配置键，以及为它赋值的环境变量。

## 解决方法

在服务端运行的环境中，把列出的环境变量设置为有效的值：

```bash [Terminal]
NUXT_API_SECRET=my-secret NUXT_PORT=8080 node .output/server/index.mjs
```

如果并非总是需要该值，请在 `nuxt.config` 中为它提供默认值或将其设为可选：

```ts [nuxt.config.ts]
import { z } from 'zod'

export default defineNuxtConfig({
  runtimeConfig: {
    apiSecret: z.string().optional(),
    port: 3000,
  },
})
```
