# E4016

当前路由匹配到一个嵌套页面，但父页面组件没有渲染 `<NuxtPage />`。Vue Router 只能在其父级的 `<NuxtPage />` 出口内显示子页面，因此子页面永远不会被显示。

当目录结构如下，且 `parent.vue` 不包含 `<NuxtPage />` 时，会发生这种情况：

```bash [目录结构]
-| pages/
---| parent/
------| child.vue
---| parent.vue
```

## 解决方法

将 `<NuxtPage />` 添加到父页面组件中，以便子路由能够在其中渲染。如果你本无意创建嵌套路由，请重新组织你的 `pages/` 目录，使该页面不再拥有子路由。

:::
