# B5033

`nuxt.options.runtimeConfig` 中的一个值是一个 [schema](/docs/guide/going-further/runtime-config#validating-with-a-schema)。Nuxt 会在加载配置时以及模块调用 `updateRuntimeConfig()` 时，用 schema 的默认值替换 schema 本身。直接赋值给 `nuxt.options.runtimeConfig` 的 schema 永远不会被替换，因此读取它的模块拿到的会是 schema 本身而不是一个值。

## 解决方法

在模块中，把 schema 传给 [`updateRuntimeConfig()`](/docs/api/kit/runtime-config#updateruntimeconfig)：

```ts [module.ts]
import { defineNuxtModule, updateRuntimeConfig } from '@nuxt/kit'
import { z } from 'zod'

export default defineNuxtModule({
  setup (_options, nuxt) {
    nuxt.options.runtimeConfig.myModule = z.object({ apiKey: z.string() }) // [!code --]
    updateRuntimeConfig({ myModule: z.object({ apiKey: z.string() }) }) // [!code ++]
  },
})
```

如果这个模块不是你自己编写的，请向模块作者报告该问题。
