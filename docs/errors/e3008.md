# E3008

`useAsyncData()` 在没有有效键的情况下被调用。第一个参数必须是非空字符串，以便 Nuxt 能够在组件之间缓存并去重该请求。

## 解决方法

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
