# B5003

你在 `runtimeConfig.app` 下使用了自定义键，该命名空间是 Nuxt 为内部值（如 `baseURL` 和 `cdnURL`）保留的。这里的自定义键可能会与 Nuxt 自身的配置冲突。

## 解决方法

将自定义键移动到 `runtimeConfig.public`（暴露给客户端），或移动到一个顶层的自定义命名空间（仅服务端）：

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    // 替代 runtimeConfig.app.myKey
    public: {
      myKey: 'value',
    },
  },
})
```
