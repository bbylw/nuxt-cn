# E1001

一个需要 Nuxt 实例的组合式函数（`useNuxtApp()`、`useRoute()`、`useFetch()` 等）在插件、Nuxt 钩子、路由中间件或 Vue `setup()` 之外运行了。最常见的触发场景是在异步回调（`setTimeout`、`.then()`、`await` 之后）中调用它，此时上下文已经丢失。

## 解决方法

在 `setup()` / 插件 / 中间件的顶部同步调用该组合式函数，并在之后复用捕获到的结果。对于服务端异步操作，请用 `nuxtApp.runWithContext()` 包裹该调用。
