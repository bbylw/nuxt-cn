# E1006

`onPrehydrate()` 在没有经过 Nuxt 构建流水线转换的情况下运行了。它需要编译时处理，并且仅在服务端生效，因此当你从 Nuxt 没有转译的依赖中调用它时，就会出现这种情况。

## 解决方法

将有问题的库添加到 `nuxt.config.ts` 的 `build.transpile` 中，这样构建流水线就能处理它的 `onPrehydrate()` 调用。
