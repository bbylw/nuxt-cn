# E1007

像 `definePageMeta()` 这样的编译期宏在运行时执行了。这些辅助函数会被 Nuxt 构建转换掉，绝不能动态运行。这通常意味着该宏在某个组合式函数或非页面组件中调用，而不是直接在页面中调用。

## 解决方法

仅能在页面组件 `<script setup>` 的顶层调用该宏。它不能在组合式函数、条件语句或非页面组件中使用。
