# E7007

`useState()` 接收到了非函数的初始值。初始化函数必须是一个函数，这样它才只在服务端运行一次，并且其结果可以被序列化到 payload 中用于水合（hydration）。

## 解决方法

```ts
const counter = useState('counter', () => 0)
```
