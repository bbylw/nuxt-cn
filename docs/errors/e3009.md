# E3009

`useAsyncData()` 在没有处理函数的情况下被调用。处理函数就是执行获取并返回数据的函数，因此它不能被省略，也不能是其他类型。

## 解决方法

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
