# E8007

使用 `features.noScripts: 'production'`（启用 `noScripts` 时的默认值）时，只有在生产构建中才会从渲染出的 HTML 里移除脚本。在开发环境中页面仍然会下发 JavaScript，因此依赖它的行为（惰性水合策略、服务端组件内的 `nuxt-client` 组件）在开发时看起来是正常的，部署之后却会静默失效。

当渲染的某个路由使用了这些特性之一时，会在开发期间发出此警告。

## 解决方法

要么从受影响的路由中移除对客户端的依赖，要么使用 `noScripts` 路由规则把脚本移除限定在真正静态的路由上（该规则在开发环境中同样生效，因此任何破坏都能立刻被发现）：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    '/static/**': { noScripts: true },
  },
})
```

或者，设置 `features.noScripts: 'all'`，在开发环境中也移除脚本，从而在开发时就能观察到生产环境的行为。
