# E2005

`useRoute()` 在路由中间件内部被调用（直接调用，或通过另一个组合式函数调用）。在那时目标路由尚未解析，因此 `useRoute()` 可能返回意外的值；中间件将 `to` 和 `from` 路由作为参数接收，应使用它们。

## 解决方法

```ts
export default defineNuxtRouteMiddleware((to, from) => {
  // 使用 `to` / `from`，而不是 useRoute()
})
```
