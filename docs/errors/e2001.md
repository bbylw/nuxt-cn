# E2001

`navigateTo()` 接收到一个外部 URL，但没有 `{ external: true }` 选项。Nuxt 要求对外部导航进行显式选择加入，以避免意外将用户重定向离开你的应用。

## 解决方法

```ts
navigateTo('https://example.com', { external: true })
```
