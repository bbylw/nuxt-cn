# B3014

模板在服务端组件上使用了 `v-on`（或 `@`）或 `v-model`。服务端组件只在服务端渲染，并且不会为自己下发任何 JavaScript，因此它们永远不会发出事件，也无法更新 `v-model` 绑定。监听器不会被调用。

除非禁用 [`experimental.templateDiagnostics`](/docs/guide/going-further/experimental-features#templatediagnostics)，否则会报告此警告。`@error` 不会被报告：服务端组件在加载失败时会发出 `error` 事件。

## 解决方法

在客户端渲染需要交互的部分。你可以将该服务端组件与同名的 `.client.vue` 组件配对，或使用 `nuxt-client` 属性渲染一个可交互的子组件（需要启用 `experimental.componentIslands.selectiveClient`），也可以把监听器移动到包裹该服务端组件的客户端组件上。

```vue [app/components/Counter.server.vue]
<template>
  <div>
    <!-- 在服务端渲染，然后在水合时于客户端激活 -->
    <CounterButton nuxt-client />
  </div>
</template>
```
