# B4025

模板中包含一个 `to`（或 `href`）为静态值的 `<NuxtLink>`，它没有匹配到任何页面路由，因此访问该链接会显示 404 页面。

除非禁用 [`experimental.templateDiagnostics`](/docs/guide/going-further/experimental-features#templatediagnostics)，否则会报告此警告。只会检查静态的绝对路径：使用绑定的 `:to` 的链接、外部 URL、相对路径、仅含 hash 或仅含查询参数的链接，以及带有 `external` prop 的链接都不会被检查。动态路由片段和全捕获（catch-all）路由可以匹配任意值，被路由规则重定向的路径也是允许的。

只能作为某个路由的前缀匹配到的路径同样会被报告：如果只有 `app/pages/users/[id].vue`，那么指向 `/users` 的链接就没有可渲染的页面。

## 解决方法

检查路径是否存在拼写错误，或者添加它本应指向的页面。如果链接指向的不是页面（例如服务端路由、`public/` 中的文件，或同一域名下的另一个应用），请设置 `external` prop，让浏览器而不是 Vue Router 来处理它：

```vue
<template>
  <NuxtLink
    to="/api/export.csv"
    external
  >
    Download
  </NuxtLink>
</template>
```
