# E4012

Nuxt 无法解析渲染服务端组件（island）时返回的响应。这通常意味着服务端组件端点返回了预期 island 载荷之外的内容，例如错误页面或格式错误的 HTML。

## 解决方法

检查服务端组件是否存在会阻止其渲染的错误，并确认 island 端点返回了有效的响应。检查 island 请求的网络响应，看看服务端实际返回了什么。
