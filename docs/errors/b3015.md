# B3015

模板把一个函数、一个类或一个类的实例（例如 `new Date()`）作为 prop 传给服务端组件，或者把它传入 `<NuxtIsland>` 的 `props` 或 `context` 中。服务端组件的 prop 会被序列化为 JSON 并发送到服务端以渲染该组件，因此这些值无法完整地到达组件。

除非禁用 [`experimental.templateDiagnostics`](/docs/guide/going-further/experimental-features#templatediagnostics)，否则会报告此警告。只会检查在模板中可见的值：内联函数、`new` 表达式，以及在 `<script setup>` 顶层声明的函数或类。

## 解决方法

只传递可以 JSON 序列化的值（字符串、数字、布尔值、`null`、数组和普通对象），并把需要该函数的逻辑移动到服务端组件内部：

```diff [app/pages/index.vue]
 <template>
-  <PriceTag :format="value => `$${value}`" :value="price" />
+  <PriceTag currency="USD" :value="price" />
 </template>
```

如果组件确实需要来自父组件的函数，请把它改为在客户端渲染，而不是作为服务端组件渲染。
