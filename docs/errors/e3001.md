# E3001

传递给 `useFetch()` 的 URL 以 `//` 开头。像这样协议相对的 URL 会解析到外部主机，这几乎从来不是本意，因此被拒绝以避免将请求泄漏到不同的源。

## 解决方法

使用带有显式协议的绝对 URL，或者相对路径：

```ts
useFetch('/api/data')
useFetch('https://api.example.com/data')
```
