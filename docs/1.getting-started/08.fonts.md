Nuxt 有一个核心模块（[`@nuxt/fonts`](https://nuxt.com/modules/fonts)），用于优化你的 Web 字体并移除外部网络请求，从而改善隐私与性能：

- **自托管（Self-hosting）：** Nuxt Fonts 在构建时下载字体，并使用长生命周期缓存响应头从你自己的域名投递它们。浏览器不会再为这些字体向 Google 或其他字体提供商发送请求。请移除任何通过 `<link>` 标签或 `@import` 规则从提供商加载字体的写法，因为 Nuxt Fonts 不会处理它们。
- **更少的布局偏移：** Nuxt Fonts 会调整本地系统字体，使其度量指标与每个 Web 字体匹配。当 Web 字体加载时，文本几乎不会发生位移。
- **无需编写代码：** 只需在你的 CSS 中的 `font-family` 声明里写出字体名称。Nuxt Fonts 会找到该字体并为你生成 `@font-face` 规则。

## 安装（Installation）

将 Nuxt Fonts 模块添加到你的项目：

```bash [Terminal]
npx nuxt add fonts
```

这条命令会安装 `@nuxt/fonts` 并将其添加到你的 `nuxt.config` 的 `modules` 中。

## 用法（Usage）

要使用某个字体，请在你的 CSS 中添加 `font-family` 声明：

```vue [app/app.vue]
<template>
  <h1>Hello Nuxt Fonts!</h1>
</template>

<style scoped>
h1 {
  font-family: 'Roboto', sans-serif;
}
</style>
```

Nuxt Fonts 会识别出 `Roboto`，并通过字体提供商解析它。随后它会把 `@font-face` 规则注入到同一份样式表中。

字体会在你的 CSS 使用到它们的地方加载。若要将某个字体应用到整个应用，请在全局样式表中声明它，并把该样式表添加到你的 `nuxt.config` 的 [`css` 属性](/docs/getting-started/styling#the-css-property)中：

:::code-group

```css [app/assets/css/main.css]
body {
  font-family: 'Inter', sans-serif;
}
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  css: ['~/assets/css/main.css'],
})
```

:::

Nuxt Fonts 只解析 `font-family` 列表中的第一个字体。它会使用列表中的其他字体（例如 `sans-serif`）来生成回退（fallback）度量指标。

:::warning
Nuxt Fonts 只处理 CSS 样式表和 `<style>` 块。内联 `style` 属性中的 `font-family` 不会被识别。请参阅[未被识别的字体](#fonts-that-arent-detected)。
:::

## Web 字体（Web Fonts）

Nuxt Fonts 会从多个 Web 字体提供商解析字体，例如 [Google Fonts](https://fonts.google.com)、[Bunny Fonts](https://fonts.bunny.net)、[Fontshare](https://www.fontshare.com) 和 [Fontsource](https://fontsource.org)。你不需要配置它们：第一个拥有该字体的提供商就会投递它。

默认情况下，Nuxt Fonts 会加载 `normal` 和 `italic` 两种样式中的 `400 700` 字重范围。当某个字体家族存在可变字体（variable font）时，Google Fonts 和 Fontsource 会投递[可变字体](https://fonts.google.com/knowledge/introducing_type/introducing_variable_fonts)。可变字体用一个文件覆盖一段字重范围，而不是为每个字重提供一个文件。

要加载其他字重，或为某个字体指定提供商，请在 `nuxt.config` 的 `fonts.families` 选项中配置该字体：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      // 加载可变 Inter 字体的所有字重
      { name: 'Inter', weights: ['100 900'] },
      // 只从 Google Fonts 加载 Roboto 的这几个字重
      { name: 'Roboto', weights: [400, 700], provider: 'google' },
    ],
  },
})
```

要想对所有字体使用相同的选项，请改为在 `fonts.defaults` 中设置。你还可以更改 Nuxt Fonts 加载的子集（subsets），例如为了支持西里尔字母或阿拉伯文文本。全部选项请参阅[字体选项](https://nuxt.com/modules/fonts/configuration#font-options)。

## 本地字体（Local Fonts）

要使用你自己的字体文件，请将它们存放在 [`public/`](/docs/directory-structure/public) 目录中。Nuxt Fonts 会扫描其中的 `woff2`、`woff`、`ttf`、`otf` 和 `eot` 文件，并将它们与你的 CSS 中的 `font-family` 名称匹配。

文件名会告诉 Nuxt Fonts 每个文件的字重与样式。没有标注字重或样式的文件视为 `normal` 样式下的 `400` 字重：

```bash [Directory structure]
-| public/
---| fonts/
-----| my-font.woff2              # 400, normal
-----| my-font-bold.woff2         # 700, normal
-----| my-font-700-italic.woff2   # 700, italic
```

然后按名称使用该字体：

```css [app/assets/css/main.css]
body {
  font-family: 'My Font', sans-serif;
}
```

Nuxt Fonts 会把 `My Font` 转换为 `my-font` 来查找文件。

对于可变字体，请把它的字重范围写进文件名，例如 `public/fonts/my-variable-font-100-900.woff2`。标记为 `variable` 或 `VF` 但没有写范围的文件名会被视为覆盖 `100 900`。即使是可变字体文件，Nuxt Fonts 也只声明[默认字重](#web-fonts)（即 `400 700`），因此其他字重会渲染为该范围内最接近的字重。要使用它的完整范围，请配置该字体的字重：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      { name: 'My Variable Font', weights: ['100 900'] },
    ],
  },
})
```

然后按名称使用该字体：

```css [app/assets/css/main.css]
h1 {
  font-family: 'My Variable Font', sans-serif;
  font-weight: 900;
}
```

要使用文件名不同的字体文件，或使用托管在别处的文件，请在 `fonts.families` 中设置它的 `src`。你可以重复同一个字体名称，从而为每个字重添加一个文件：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      { name: 'Brand Font', src: '/brand-regular.woff2', weight: 400 },
      { name: 'Brand Font', src: '/brand-black.woff2', weight: 900 },
    ],
  },
})
```

## 未被识别的字体（Fonts That Aren't Detected）

Nuxt Fonts 只解析它在你的 CSS 中发现的字体。它不会识别内联样式、内联 SVG、第三方样式表中的字体，也不会识别仅在运行时应用的字体。

对于这类字体，请在 `fonts.families` 中设置 `global: true`。这样 Nuxt Fonts 就会把该字体的 `@font-face` 规则添加到每个页面：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      { name: 'Anton', global: true },
    ],
  },
})
```

每位访客都会下载每个全局字体对应的 CSS，因此请只在确实需要时使用这个选项。

这个选项不适用于你通过 `<img>` 标签加载的 SVG 文件，因为它们无法使用页面的字体。请改为把这些字体嵌入到这些 SVG 文件中。

## Tailwind CSS

Nuxt Fonts 会读取 Tailwind CSS 生成的 CSS，因此你可以把字体声明为主题变量：

```css [app/assets/css/main.css]
@import "tailwindcss";

@theme {
  --font-display: 'Inter', sans-serif;
}
```

然后使用 `font-display` 工具类（utility class）应用该字体。更多细节（包括 UnoCSS 的用法）请参阅 [Nuxt Fonts 使用指南](https://nuxt.com/modules/fonts/usage#tailwind-css)。
