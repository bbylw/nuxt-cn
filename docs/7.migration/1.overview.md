---
title: 概述
description: Nuxt 3 是对 Nuxt 2 的完整重写，并且基于一套全新的底层技术。
---

将 Nuxt 2 应用迁移到 Nuxt 3 时存在重大变化，不过随着我们向稳定版推进，迁移应该会变得更加直接。

:::note
本迁移指南正在根据 Nuxt 3 的开发进展持续完善。
:::

其中一些重大变化包括：

1. 从 Vue 2 迁移到 Vue 3，默认采用 Composition API 和 script setup。
1. 从 webpack 4 和 Babel 迁移到 Vite 或 webpack 5 与 esbuild。
1. 从运行时的 Nuxt 依赖迁移到一个使用 nitropack 编译的、极简且独立运行的服务器。

:::tip
如果你需要停留在 Nuxt 2，但又想在 Nuxt 2 中受益于 Nuxt 3 的功能，可以转而查看[如何开始使用 Bridge](/docs/bridge/overview)。
:::
