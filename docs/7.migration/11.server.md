---
title: 服务器
description: '了解如何从 Nuxt 2 迁移到 Nuxt 3 的服务器。'
---

在构建好的 Nuxt 3 应用中，没有运行时的 Nuxt 依赖。这意味着你的站点将具有极高的性能，并且极其精简。但这也意味着你不能再钩入运行时的 Nuxt 服务器钩子。

:read-more{to="/docs/guide/concepts/server-engine"}

## 步骤

1. 移除你 `nuxt.config` 中的 `render` 键。
2. `~~/server/api` 和 `~~/server/middleware` 中的任何文件都会被自动注册；你可以将它们从你的 `serverMiddleware` 数组中移除。
3. 将你 `serverMiddleware` 数组中的任何其他项更新为直接指向文件或 npm 包，而不是使用内联函数。
