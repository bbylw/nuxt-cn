---
title: 自动导入
description: Nuxt 3 采用最小摩擦的方式，即在任何可能的地方自动导入组件和组合式函数。
---

:::note
在其余的迁移文档中，你会发现关键的 Nuxt 和 Vue 工具并没有显式的 import 语句。这不是笔误；Nuxt 会自动为你导入它们，并且如果你已经按照[说明](/docs/migration/configuration#typescript)使用了 Nuxt 的 TypeScript 支持，应该能获得完整的类型提示。
::

[阅读更多关于自动导入的内容](/docs/guide/concepts/auto-imports)

## 迁移

1. 如果你在 Nuxt 2 中使用过 `@nuxt/components`，可以从你的 `nuxt.config` 中移除 `components: true`。如果你有更复杂的配置，请注意组件选项已经有所变化。详见[组件文档](/docs/directory-structure/app/components)。

:::tip
你可以查看 `.nuxt/types/components.d.ts` 和 `.nuxt/types/imports.d.ts`，了解 Nuxt 是如何解析你的组件和组合式函数自动导入的。
::
