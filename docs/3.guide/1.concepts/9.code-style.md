## ESLint

Nuxt 推荐的方式是使用 [`@nuxt/eslint`](https://eslint.nuxt.com/packages/module) 模块启用 ESLint 支持，它会为你设置具有项目感知能力的 ESLint 配置。

::callout{icon="i-lucide-lightbulb"}
该模块是为[新的 ESLint 扁平配置格式](https://eslint.org/docs/latest/use/configure/configuration-files)设计的，这是[自 ESLint v9 起的默认格式](https://eslint.org/blog/2024/04/eslint-v9.0.0-released/)。如果你使用的是传统的 `.eslintrc` 配置，你将需要[用 `@nuxt/eslint-config` 手动配置](https://eslint.nuxt.com/packages/config#customizing-the-config)。我们强烈建议你迁移到扁平配置，以面向未来。
::

## 快速设置

```bash
npx nuxt add eslint
```

启动你的 Nuxt 应用后，会在你的项目根目录生成一个 `eslint.config.mjs` 文件。你可以根据需要自定义它。

你可以在 [Nuxt ESLint 文档](https://eslint.nuxt.com/packages/module) 中了解更多关于该模块和自定义的内容。
