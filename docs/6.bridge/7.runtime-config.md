## 更新运行时配置

Nuxt 3 处理运行时配置的方式与 Nuxt 2 不同，使用了新的组合 `runtimeConfig` 选项。

首先，你需要将 `publicRuntimeConfig` 和 `privateRuntimeConfig` 属性合并到一个名为 `runtimeConfig` 的新属性中，公共配置放在名为 `public` 的键中。

```diff
// nuxt.config.js
- privateRuntimeConfig: {
-   apiKey: process.env.NUXT_API_KEY || 'super-secret-key'
- },
- publicRuntimeConfig: {
-   websiteURL: 'https://public-data.com'
- }
+ runtimeConfig: {
+   apiKey: process.env.NUXT_API_KEY || 'super-secret-key',
+   public: {
+     websiteURL: 'https://public-data.com'
+   }
+ }
```

这也意味着，当你需要访问公共运行时配置时，它位于名为 `public` 的属性后面。如果你使用了公共运行时配置，你将需要更新你的代码。

```diff
// MyWidget.vue
- <div>Website: {{ $config.websiteURL }}</div>
+ <div>Website: {{ $config.public.websiteURL }}</div>
```
