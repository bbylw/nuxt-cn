## “我搞不清楚如何（……）。”

你已经阅读了这些文档，认为应该是可行的，但还不清楚具体怎么做。最好的办法是[打开一个 GitHub Discussion](https://github.com/nuxt/nuxt/discussions)。

请不要因为问了一个你认为很简单的问题而感到尴尬——我们都有过这种经历！❤️

你遇到的每个人都是出于关心才来帮忙的，而不是因为拿工资。最体贴的做法就是让他们更容易帮助你。以下是一些建议：

- _说明你的目标是什么，而不只是你遇到的问题。_ “我需要确保我的表单输入是可访问的，所以我想让服务端和客户端的 id 能够匹配。”
- _确保你已经先阅读了文档并使用了你喜欢的搜索引擎。_ 可以这样说：“我 Google 搜索了 'nuxt script setup'，但在任何地方都找不到代码示例。”
- _说明你已经尝试过什么。_ 告诉别人你试验过哪些解决方案，以及原因。这通常能让别人的建议更贴合你的情况。
- _分享你的代码。_ 如果人们只看到一个错误信息或截图，他们可能无法帮忙——但如果你以可复制粘贴的形式（最好是像 CodeSandbox 这样的最小复现）分享代码，情况就完全不同了。

最后，直接提问就好！没必要[请求提问许可](https://dontasktoask.com)，也无需[等别人回复你的“你好”](https://www.nohello.com)。如果你这样做，可能得不到回复，因为人们在看到完整问题之前会一直在等待。

## “这会不会是个 bug？”

某些功能没有按照文档所说的方式工作。你不确定这是不是 bug。你已经搜索了[已存在的问题](https://github.com/nuxt/nuxt/issues)和[讨论](https://github.com/nuxt/nuxt/discussions)，但找不到相关内容。（如果有已关闭的问题，请重新创建一个。）

我们建议你查看[如何报告 bug](/docs/community/reporting-bugs)。Nuxt 仍在积极开发中，每一个问题都有助于让它变得更好。

## “我需要专业帮助”

如果社区无法在你所需的时间范围内提供所需的帮助，NuxtLabs 通过[Nuxt Experts](https://nuxt.com/enterprise/agencies)提供专业支持。

Nuxt Expert 的目标是为 Vue 生态提供支持，同时为那些为开源解决方案做出贡献的人创造自由职业机会，从而帮助维护生态的可持续发展。

Nuxt experts 是由 Nuxt、Vue 和 Vite 精选的贡献者组成，提供专业支持和咨询服务。
